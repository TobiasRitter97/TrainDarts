Dark Mode, hoher Kontrast, angelehnt an Sisal-Matte und Spinnendraht am echten Board. Rot/Grün/Gold/Blau sind bewusst zurückhaltend eingesetzt statt als Neon-Flächen (SPEC §11).

Buttons

Alle Buttons erfüllen die Mindest-Touch-Größe (56px). UNDO ist bewusst nicht als "gefährlicher" roter Button gestaltet, da es eine häufige, normale Aktion ist (SPEC §16).

Scores & Darts

Zielanzeige und Wurf-Chips wie im einheitlichen Game Screen (SPEC §12). Trefferfarben sind Feedback, keine Deko: grün = Treffer, blau = Triple, gedämpft = Miss.

Touch Targets

Mindestgröße 56×56px für jedes interaktive Element — auf einem Tablet neben der Scheibe muss jeder Button auch im Stehen sicher treffbar sein.

56×56
= --touch-min, gilt für Buttons, Dart-Chips, Korrektur-Optionen

Responsive-Prioritäten (SPEC §39)

Das Layout wird für den größten Bildschirm entworfen und bricht kontrolliert nach unten um — nicht umgekehrt:

  1. 16:9 Dart Display / TV (Referenzlayout)
  2. Tablet Landscape
  3. Desktop
  4. Tablet Portrait (Scoreboard bricht um)
  5. Smartphone (einspaltig, niedrigste Priorität)
